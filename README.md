# Hi, I'm Prachi 👋

Bioinformatics and software, somewhere between the wet-lab questions and the code that
answers them. I like taking a messy public dataset or a vague "can we predict X" and
turning it into something that runs end to end, with the results written down honestly.

### Pinned projects

**🧬 [Single-cell RNA-seq of immune cells](https://github.com/prachithakur7330-sudo/scrna-immune-cell-analysis)**
A Scanpy pipeline on 10,000 PBMCs from healthy donors — QC, normalisation, PCA/UMAP,
Leiden clustering and marker-based annotation. Recovers 11 immune cell types.
*Python, Scanpy, scikit-learn.*

**💊 [GNN for drug–target interaction](https://github.com/prachithakur7330-sudo/gnn-drug-target-interaction)**
A graph neural network that predicts drug–target binding affinity on the DAVIS kinase
dataset. Drugs become molecular graphs (RDKit), proteins go through a 1D CNN, trained
end to end.
*PyTorch, PyTorch Geometric, RDKit.*

**🏥 [Hospital Management System](https://github.com/prachithakur7330-sudo/hospital-management-system)**
A Java + MySQL app for patients, doctors and appointments, with the scheduling rules
enforced in both the service layer and the database. JDBC, a clean DAO/service split,
and a test suite.
*Java 17, MySQL, JUnit 5.*
